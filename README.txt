ROCKET CALIENTE — versión reconstruida del apartado «Sobre Nosotros»

- index.html: página autónoma reconstruida a partir del contenido público de https://rocketcaliente.com/sobre/
- css/styles.css: estilos de esta reconstrucción.
- js/main.js: archivo JS mínimo.

- dafo00 se añade al final de la lista «Mods RosdriArmy».

IMPORTANTE SOBRE LA FIDELIDAD:
La página pública permite consultar el texto y el orden de los integrantes, pero no expone al navegador de investigación todos los archivos originales de diseño (CSS, fuentes, scripts y recursos). Por eso este ZIP es una reconstrucción independiente y NO una copia pixel-perfect ni una modificación de los archivos originales. Para mantener la fotografía solicitada se usa la URL pública original; hace falta conexión a Internet para cargarla. Los demás retratos se representan con marcadores neutros, no con imágenes inventadas.

Para probarlo: descomprime el ZIP y abre index.html en un navegador.
No se ha modificado la web publicada.
